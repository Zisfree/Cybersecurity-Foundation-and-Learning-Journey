## Creating python server
- Creating a python server on your system, to transfer or download any file on any other system is a very convenient method to transfer files. When we create a python server using `python3 -m http.server`, we basically are making a server in our directory where we run this module(This will run on port 8000 if not mentioned.).
- After creating this server we can access it from anywhere cause it is basically connected to the internet.
